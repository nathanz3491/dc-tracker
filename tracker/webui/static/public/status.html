        How this page knows

        Every few minutes the server asks each public address for a page, over the internet, the way a reader would. A page that answers is up; one that fails twice running is down.

        The checks run on the same server as everything they check, so when that server is off nothing is checked at all. A stretch with no checks is counted as downtime for every address, and marked as a restart when the machine booted during it — never left out, which would make the worst days look the best.

        The nightly update is read from its own log. Times are shown in your time zone.
