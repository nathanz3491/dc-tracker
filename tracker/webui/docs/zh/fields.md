# 字段说明

本页列出园区的每一个字段、它的含义，以及当来源有分歧时追踪系统如何选定其数值。列名与 [Projects](projects)（项目）页面上显示的一致；`code` 格式的名称是字段的内部名称，用于[项目详情页](project-page)。

在每个字段自身的规则生效之前，所有字段都遵循同样的先后顺序：已被排除的说法不再计入；已引证的说法优先于待确认的说法；整个园区的数字优先于单栋楼的数字；第一手来源优先于目录网站。参见[数值从哪里来](provenance)。

## 十二个追踪字段

| 列 | 字段 | 含义 | 来源有分歧时 |
| --- | --- | --- | --- |
| **Project**（项目） | `name` | 园区的名称。 | 保留最先看到的名称；之后出现的名称不会取代它。 |
| **Operator**（运营商） | `company` | 建设并运营该园区的公司。 | 保留最先看到的。其他参与的公司列在 *Who is involved*（相关公司）下。 |
| **Buyer**（买方） | `customer` | 将入驻并使用其算力的租户。 | 采用最可靠、最新的来源。如果没有来源指明买方，可能取自被称为客户的公司，或取自其最大楼栋的租户，并标注为*推导（derived）*。 |
| **City**（城市） | `city` | 园区归档所在的镇。 | 最先看到的。 |
| **State**（州） | `state` | 两个字母的美国州代码。 | 最先看到的。 |
| **Phase**（阶段） | `phase` | 项目进展到哪一步。参见[阶段与进展](progress)。 | 来自可信来源的停止状态（暂停、已取消）优先；否则取已引证来源所支持的最靠后的阶段——且不低于园区已达到的里程碑：许可获批至少是审批中，动工至少是建设中。 |
| **Planned (MW)**（规划容量，MW） | `mw_planned` | 规划容量，指计算（IT）负载，单位为兆瓦。 | 采用最可靠、最新的来源。只有在没有覆盖整个园区的数字时，才采用单栋楼的数字。 |
| **Running (MW)**（运行容量，MW） | `mw_built` | 目前已投运的容量。 | 取任一来源给出的**最大**数字。在有任何部分投入运行之前显示为*不适用（n/a）*。 |
| **Investment (USD)**（投资，美元） | `investment_usd` | 宣布的园区投资额，以美元计。 | 采用最可靠、最新的来源。整体计划、区域和资产组合的总数不计入。 |
| **Announced**（宣布时间） | `first_announced` | 园区首次公开的时间。 | 取任一来源给出的**最早**日期。 |
| **Online**（上线时间） | `expected_online` | 预计上线的时间。 | 采用最可靠、最新的来源。日期推后会记录一个*延期（delayed）*里程碑。 |
| **Biggest obstacle**（最大障碍） | `blocker` | 用一句话描述的最严重的未解决障碍。 | 根据各项障碍得出：有原句的优先于没有原句的，其次取最严重的。没有未解决障碍时为空。 |

## 其他字段

| 列 | 字段 | 含义 |
| --- | --- | --- |
| **County**（县） | `county` | 所在县。如果某个镇只位于一个县内，则根据人口普查数据填写。 |
| **Lat**、**Lon**（纬度、经度） | `lat`, `lon` | **镇或县的中心点**，取自人口普查数据——不是场地本身的位置。 |
| **Compute (H200-eq)**（算力，H200 等效） | `h200_equivalent` | 把容量换算成 NVIDIA H200 加速器的数量，约每兆瓦 770 个。来源明确给出的芯片数量优先。*推导（derived）。* |
| **Confidence (0-3)**（可信度，0-3） | `confidence` | 该行记录的依据有多充分。参见[可信度](confidence)。 |
| **Verified**（核实时间） | `last_verified_at` | 最近一次由人工核查并确认该行记录的时间。 |
| — | `country` | 始终为美国。 |
| — | `notes` | 决定与披露：被排除的数字、合并、已搜索但未找到的字段。 |

## 关于每个数字

数值背后的每条说法都可以带有限定信息；当它们不属于常规情况时，会显示在该数值的弹出框中：

| 限定项 | 取值 | 含义 |
| --- | --- | --- |
| **bound**（精确程度） | 精确（exact）、约数（approximate，~）、至少（at least，+）、至多（at most，≤） | 来源陈述这个数字的精确程度。 |
| **scope**（范围） | 本场地（this site）、整体计划（programme）、区域（region）、资产组合（portfolio）、单栋楼（one building）、某个具名的期（a named phase） | 这个数字涵盖的范围。 |
| **modality**（确定程度） | 推测（speculated）、目标（targeted）、规划（planned）、已签约（contracted）、已实现（achieved） | 来源陈述它的确定程度。 |
| **as of**（截至） | 一个日期 | 这个数字成立的时间，如果不同于文章日期。 |
| **basis**（口径） | IT 负载（IT load）、设施总功率（facility，◒）、铭牌容量（nameplate，⚡）、未说明（not stated） | 仅用于兆瓦数：指的是哪种量。参见[数字与日期](numbers-and-dates)。 |
| **precision**（精度） | 日（day）、月（month）、季度（quarter）、半年（half）、年（year） | 仅用于日期：来源给出日期的精确程度。 |

## 相关公司

运营商以外的公司被记录为**相关方**，每一方都有一个角色——开发商、业主、运营商、客户、公用事业公司或承包商——以及提到它们的原句。

## 分期

分期是园区中的一栋楼、一期或一个机房，有自己的名称、容量、状态、租户、日期和投资额。其状态为以下之一：规划中（planned）、审批中（permitting）、在建（under construction）、主体完工（shell complete，已建成但未通电）、已通电（energized，电力已接通）、服务中（serving，已有客户在其上运行）、暂停（paused）或已取消（cancelled）。参见[项目详情页](project-page)。

## 里程碑与障碍

里程碑是五条进展轨道上带日期的事件：已宣布、已获得土地、已提交许可申请、许可已批准、签订电网接入协议、场地施工、动工、设备安装完成、通电、首个客户——另外还有*延期（delayed）*和*扩建（expanded）*。障碍有类型、严重程度和状态。参见[阶段与进展](progress)。
