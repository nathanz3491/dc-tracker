# 公司页面

每家公司都有一个页面，地址为 `/companies/<name>`，列出它建设或使用的所有园区。你可以从[项目详情页](project-page)上的公司名称、[Monitor](monitor)（关注）卡片或关注列表条目进入。

## 页头

- 公司的标志（取自其网站图标）或名称首字母、公司名称和网站。
- 一行概要，例如 *builds 12 · tenant on 3 · in 7 states*（建设 12 个 · 在 3 个中为租户 · 分布于 7 个州）。
- **☆ Watch company**（关注公司）会把这家公司加入你的关注列表，覆盖它作为运营商、开发商或租户的每一个园区。**★ Watching**（关注中）则将其移除。

## 数字卡片

| 卡片 | 含义 |
| --- | --- |
| **campuses**（园区） | 园区数量，分为该公司建设的和作为租户使用的。下方表格中的每个园区都计入此数，不论它是否计入容量数字。 |
| **planned**（规划） | 规划容量，按 [Capex](capex)（资本支出）页面的方式计算。 |
| **running**（运行） | 已投运的容量，计算方式相同。 |
| **open obstacles**（未解决障碍） | 这些园区上尚未解决的障碍，不论多久以前报道。 |

卡片下方的一行说明这两个容量数字是如何计算的。它们遵循 [Capex](capex) 页面的规则：

- 疑似被重复记录的园区只计算一次（见[重复记录](duplicates)）；
- 暂停和取消的园区不计入；
- 只租用园区中部分楼栋的租户，只计入这些楼栋，而不是整个园区。

因此 **planned** 等于该公司在 Capex 页面上自己的那一行，再加上它建设、但没有指明买方的园区——Capex 把这些园区列在 *(no named customer)*（无具名客户）之下。这一行会分别给出这两部分。它为具名租户建设的园区计入该租户，与 Capex 一致。这样每一兆瓦都只出现在一家公司的页面上，所有公司页面相加等于 Capex 的总数。这个总数可能略高于[地图](map)上的总数，原因见地图页。

## 园区

一张列出所有园区的表格，标明该公司在每个园区中的角色：**builds**（建设）、**tenant**（租户），或只使用部分楼栋时为 **tenant (tranche)**（租户（分期））；如果建设方是别人，也会列出建设方。然后是阶段、规划容量（附条形图）、运行容量和未解决障碍。点击某一行或按 Enter 键即可打开该园区。

如果某个园区没有完整计入上面的数字，角色旁会有一条简短说明：

| 说明 | 含义 |
| --- | --- |
| *not counted: cancelled*（或 *paused*） | 未计入（已取消或暂停），与 Capex 一致。 |
| *not counted: #12 is the same campus* | 疑似是 #12 号园区的第二条记录，改为计入 #12。 |
| *counted for …* | Capex 把这个园区计入另一个买方，通常是该公司为之建设的租户。 |
| *200 MW counted here, the rest for …* | 该公司只计入园区的一部分——它自己的楼栋，或扣除其他租户楼栋后剩下的部分。 |

表格旁的 **Where**（地点）显示这些园区所在的州，**Stage**（阶段）显示处于各阶段的园区数量。

## 疑似延期

当这家公司有园区属于疑似延期 —— 自己的预计上线日期已过，之后也没有任何报道表明它已投入运行 —— 页面会有一个 **Suspected delays**（疑似延期）部分，按逾期从久到短列出这些园区：园区、按来源说法给出的预计上线日期、逾期天数和阶段。标题会给出数量，并说明它们合计的规划容量。鼠标悬停某一行可看到原因，点击即可打开该园区。没有疑似延期时不显示这一部分。规则见[数字与日期](numbers-and-dates)。

## 近期新闻

**Reported in the last two months**（最近两个月的报道）列出这些园区的动态，卡片与 [Updates](updates)（动态）页面上的相同。

## 名称如何匹配

页面会按公司名称，在来源可能赋予它的所有角色中收集园区。不同写法会合并为一家（Meta 和 Facebook、AWS 和 Amazon、RagingWire 和 NTT），名称相近、实际不同的两家公司则分开处理。如果某个园区以另一家公司的名称归档，但 Capex 页面因为来源指明该公司是客户而把它计入该公司，这个园区也会列出。

公司在这里以及控制台的其他所有页面上都只用**一个名称**显示：如果它在追踪器的运营商名单上，就用名单上的名称，否则用大多数园区使用的写法。园区自己的页面在来源写法不同时，也会显示来源使用的写法。

如果你预期的某个园区没有出现，可能是它的来源写的是一家子公司或合资企业。
