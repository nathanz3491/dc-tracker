# 可信度

每个园区都有一个 0 到 3 分的**可信度**评分。它回答一个问题：在不亲自核查的情况下，这一行数据有多可信？

| 分数 | 含义 |
| --- | --- |
| **0** | 完全没有来源。 |
| **1** | 有引用，但支持较弱：只有一个次要来源，或者这一行填写的字段太少，无法判断。 |
| **2** | 有一个来源提供了扎实的支持。 |
| **3** | 有多个相互独立且说法一致的来源支持，或者经过人工核查并签字确认。 |

**单一来源永远达不到 3 分。** 无论质量多好，一篇文章只代表一个视角；最高分意味着有相互印证。

每当园区发生变化，评分都会根据来源重新计算，因此它会随着证据的增减而升降。

## 如何计算

1. **剔除**无法为任何内容担保的东西：人口普查地理数据之类的查询结果、模型推断和占位值。这些永远不会提高评分。
2. 以最强来源的权重为**起点**：公司申报文件和政府文件为 3，行业媒体为 2，一般新闻为 1，但起点最高为 2。
3. 当有两个或以上**相互独立的发布方**支持已引证的数值时，**加 1 分**。独立性按网站计算：同一网站上的五篇文章只算一次。目录网站和维基不计入，只有待确认数值的来源也不计入。
4. 当相互独立的来源在某个关键数字上**一致**时，**加 1 分**。关键数字包括：规划容量或运行容量、投资、阶段或租户。
5. 当来源在某个关键数字上**冲突**时，**减 1 分**。两个数字相差超过 20% 即视为冲突。
6. 如果园区跟踪的十二个字段中填写不到五个，**最高只能得 1 分**：信息太少，无法判断。
7. **人工签字确认**会把评分设为 3。

只要有一个真实来源，园区至少得 1 分；任何园区都不会超过 3 分。

## 它不能告诉你什么

- **它针对的是整行，而不是单个数值。** 3 分表示园区整体有充分支持，但其中某个字段仍可能是待确认。请查看你所依赖数值上的[标签](provenance)。
- **转载稿件会抬高评分。** 同一份新闻稿被多家媒体转载，看起来就像多个独立的发布方。
- **人工签字确认不会过期。** 一年前经人工核查的园区仍保持 3 分，即使之后的新闻已有变化。

这些以及其他问题，参见[已知局限](limitations)。

## 在哪里能看到

- 在[项目详情页](project-page)上，阶段旁边：*confidence N*（可信度 N）。
- 在 [Projects](projects)（项目）页面中，作为筛选条件（*1 or better*（1 分及以上）、*2 or better*（2 分及以上）、*3 only*（仅 3 分））、默认排序依据，以及开启 **All fields**（全部字段）时显示的一列。
- 在 [Map](map)（地图）上，作为着色方式之一。
