# 关注

**Monitor**（关注）页面用来选择要跟踪的对象，也用来查看你所跟踪的一切还有哪些障碍未解决。

## 你的关注列表

页面上半部分是你的列表。它决定 [Updates](updates)（动态）页面向你显示什么，以及晨报邮件包含什么。它只属于你：其他账户各有自己的列表。

每一项属于以下三种之一：

| 类型 | 如何匹配 | 如何添加 |
| --- | --- | --- |
| **company**（公司） | 该公司作为运营商、开发商或租户的每一个园区。 | 输入名称并选中。 |
| **project name**（项目名称） | 名称与你输入的词相匹配的园区。宽松匹配，按名称。 | 输入项目名称后按 Enter。 |
| **this project**（本项目） | 按编号精确对应一个园区，即使它日后改名也不受影响。 | 在该园区上点击 ☆（见下文）。 |

每一行显示它的类型、名称（链接到该园区；如果覆盖多个园区，则链接到[公司页面](companies)）、备注（如有）、匹配到多少个项目 —— 或以琥珀色显示 **no match yet**（暂无匹配）—— 以及你添加它的日期。**✕** 可删除该项。

### 添加一项

在 **watch a company, a tenant, or one project…**（关注一家公司、一个租户或一个项目……）中输入。输入框为空时，列表会推荐项目数最多的运营商和租户。

- 每条建议都标明它是什么（**operator**（运营商）、**tenant**（租户）或 **project**（项目）），以及它覆盖多少个项目或多少兆瓦。你已关注的对象会变暗，不能重复选择。
- 你输入的每个词都必须匹配。项目按名称、公司、租户、城市、县和州进行匹配。
- 如果没有任何匹配，按 **Enter** 仍会关注这个名称。一旦出现匹配的项目，它就开始报告。
- 按键：**↑ / ↓** 在列表中移动，**Enter** 选中，**Esc** 关闭列表。

租户仅列为"undisclosed"（未披露）、"unnamed"（未具名）或"confidential"（保密）的不会出现在建议中：它们不是一家你可以跟踪的公司。

### 关注单个项目：☆

☆ 按钮出现在 [Projects](projects)（项目）表格的每一行旁边，在[项目详情页](project-page)上则是一个宽按钮。

- **☆ Watch**（关注）—— 点击即按编号关注这个园区。
- **★ Watching**（关注中）—— 你已关注它；点击取消关注。
- **★ Watching via …**（通过……关注，变暗）—— 某个公司关注项或 *watch everything*（关注全部）已经覆盖了它。点击会把你带到这里来修改那一项；它不会取消关注。

### 关注全部

**watch everything**（关注全部）会把你的 Updates 页面切换为系统中的每一个园区；**watch only my list**（只关注我的列表）可切换回来。开启期间，**晨报邮件不会发送**：否则每天发出的就是整个数据库。

## 还有什么障碍

页面下半部分逐一查看你所跟踪的每个项目，看是什么在阻碍它。

### 统计块

| 统计块 | 统计内容 |
| --- | --- |
| **Projects followed**（跟踪的项目） | 你的列表覆盖多少个园区。 |
| **Blocked**（受阻） | 其中有多少个在过去两个月内有障碍被报道。 |
| **Blocking or material**（阻断或重大） | 按严重程度统计的障碍：*blocking*（阻断：工作已停止）、*material*（重大：有来源称进度或规模发生了变化）、*to watch*（关注：已被提出，但未说明影响）。 |
| **Unconfirmed**（未确认） | 有报道、但无法用引用佐证的障碍。 |

两个月内无人报道的障碍不计入此处，页面会说明有多少条。它们仍会显示在各个项目自己的页面上。

### 筛选

- **every blocker / material and worse / blocking only**（全部障碍 / 重大及以上 / 仅阻断）—— 显示的最低严重程度。
- **filter by company or project…**（按公司或项目筛选……）—— 缩小卡片范围。

### 项目卡片

- 公司（链接到它的[页面](companies)）、地点，以及项目名称（链接到[它的页面](project-page)）。
- **N open**（N 个未解决），按最严重的严重程度着色；或 **nothing open**（无未解决障碍）。
- 五个格子，每条进展轨道一个 —— 场地、审批、电力接入、施工、客户与资金 —— 每个显示 *done*（已完成）、*blocked*（受阻）、*nothing yet*（尚无进展）或当前所处位置。参见[阶段与进展](progress)。
- 每个未解决的障碍：它的严重程度和类型、它阻碍的是哪条轨道、已持续多久、摘要、发布方（在新标签页中打开文章），以及 **the quote**（原句），用于显示原句。
- 一个路标：**Would clear it:**（可解除障碍的是：）能让该轨道解除阻碍的里程碑；或 **Next step:**（下一步：）下一个里程碑；后面附上应在新闻中留意什么。

页面底部的 **Show N projects with nothing open**（显示 N 个无未解决障碍的项目）列出其余项目，**Show N unconfirmed**（显示 N 条未确认障碍）会以淡色显示无人能引证的障碍。
