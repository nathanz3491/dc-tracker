# 来源

**Sources**（来源）页面回答"这一切依据的是什么？"它列出系统读过的每一个发布方、每个发布方决定了多少已存储的数据，以及每一篇文章；你可以打开文章阅读，被引用的原句会被标出。

## 统计块

| 统计块 | 含义 |
| --- | --- |
| **X% rests on one publisher**（X% 依赖单一发布方） | 由最大的单一发布方决定的已存储数值所占的比例。这个数字高，说明数据集过于依赖一家媒体。 |
| **N publishers in all**（共 N 个发布方） | 读过的不同发布方的数量。 |
| **N values resting on them**（依赖它们的 N 个数值） | 有来源支撑的已存储数值的数量。 |

## 发布方

每个发布方一张卡片，先按它决定的已存储数值数量排序，再按读过的文章数量排序。每张卡片显示：

- 发布方的网站；
- **N stored values rest on it**（N 个已存储数值依赖它），以及它在全部数值中所占的份额 —— 或 *nothing here rests on it yet*（目前没有数据依赖它）；
- 读过它的多少篇文章；
- 琥珀色的 **N over a disagreeing source**（N 个压过了有分歧的来源）：在另一个来源说法不同的情况下，它有多少个数值被保留。这些是值得核查的数字。

**show**（显示）会列出它的文章：日期、网址、每篇支持哪些字段，以及有多少个园区引用它。

**Filter by publisher or URL…**（按发布方或网址筛选……）可缩小列表范围。它也会搜索已存储的摘录，所以一个有辨识度的短语就能找到对应的文章。

## 阅读文章

点击一篇文章即可打开。

- 顶部：发布方、来源类型、发布日期（如果发布日期未知，则为抓取日期），以及网址。
- **Reader**（阅读视图）显示发布方的文章，经提取后在这里排版，**系统引用的每一句原句都会高亮**。顶部的说明会告诉你正在阅读的是哪个版本：刚刚抓取的、已保存的副本、系统读取的纯文本，或者 —— 在无法读取全文时 —— 仅有已存储的摘录。
- **Live page**（原网页）会尝试显示发布方自己的页面。大多数发布方拒绝在其他网站中被嵌入显示，所以这里经常是空白的；请改用 **open in a new tab ↗**（在新标签页中打开 ↗）。
- 侧边面板显示该文章支持哪些字段、每个字段的原句、摘录，以及哪些园区引用了它。

**✕** 或 **Esc** 可关闭。

> [!NOTE]
> 阅读视图会从发布方自己的服务器加载文章中的图片，就像发布方的页面一样。

## 来源如何加权

并非每个来源的分量都相同。公司自己的申报文件比行业文章分量重，行业文章又比一般新闻报道分量重；目录网站和维基只用来填补没有第一手资料覆盖的空白。[数据来源](methodology)解释了权重；[可信度](confidence)解释了多个来源一致时如何提高一个园区的得分。
