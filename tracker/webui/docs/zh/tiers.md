# 质量等级

除了[可信度](confidence)之外，追踪系统还按一套阶梯式的**质量等级**为每个园区评级。可信度问的是一行数据*有多少依据*；质量等级问的是它*完成到什么程度*。追踪系统用质量等级来决定每晚优先处理哪些园区，并用来报告进展（它自己的更新报告就是以"T2 及以上的行数"来衡量的），所以你可能会在更新说明和摘要中看到它们。控制台不会在每一行上显示质量等级。

等级是逐级叠加的：一个园区只有通过某个等级及其以下所有等级的全部检查，才算达到该等级。

| 等级 | 名称 | 该园区…… |
| --- | --- | --- |
| {{tier:—}} | 无来源 | 未通过某项 T0 检查。 |
| {{tier:T0}} | **有来源** | 至少有一个真实来源，且自身没有自相矛盾之处。 |
| {{tier:T1}} | **可靠** | 没有不可能成立的数字。它计入总数的任何内容都不是虚假的。 |
| {{tier:T2}} | **完整** | 读者据以行动的字段都已填写且有依据，或者已经搜索过、确认尚未公开。 |
| {{tier:T3}} | **已定** | 所有未决问题都已有答案。 |

## T0：有来源

- 至少有一个来源不只是参考数据（例如人口普查查询结果）。
- 没有任何数值在未记录原句的情况下被当作事实呈现。
- 没有悬而未决的不可能组合，例如运行容量大于规划容量。

## T1：可靠

T1 是追踪系统的最低标准，因为它会发布汇总数字。园区满足以下条件即为可靠：

- **没有数字未通过合理性检查**：同一个数字以两种单位存储（相差一千倍）、单个园区超过 8,000 MW、单个楼栋比整个园区还大、没有原句支持的吉瓦级说法，或者投资不在每兆瓦 $0.3 million–$60 million（30 万至 6000 万美元）的范围内；
- **没有数值是由读取文章的先后顺序决定的**，而按发表顺序本应选出不同的值；
- **所有疑似重复项目都已得到处理**：已合并，或已判定为不同的园区。参见[重复项目](duplicates)。

## T2：完整

- 可衡量的字段都已填写，或不适用（尚未建成任何设施时，运行容量视为已填写）。租户和最大障碍不是必填项：这两项为空往往是正确的。
- 一个字段如果**已搜索过两次且一无所获**，就视为已有答案，并列为 *published nowhere*（未见公开），而不是缺失。当园区获得新来源时，它会自动重新打开。
- 没有数值在缺少原句的情况下被呈现为已确认。允许存在待确认的值：这一行对它们是如实标注的。

所以 T2 的意思是"就已公开的信息而言是完整的"，未知项仍会列出。

## T3：已定

- 没有未解决的警告，例如一个仍在施工的园区，其预期上线日期早已过去。
- 没有可能是同一栋楼被重复计算的分期。
- 每个未解决的障碍都有原句支持。
- 每个来源都已按追踪系统当前版本的阅读规则读过，因此没有任何内容依赖于旧版、较宽松的读取结果。
- 没有尚未判断的**疑似孪生项目**：同一县内另一个园区给出相同的数字，或名称中有相同的特征词。在每晚的重复检查对这一对作出判断之前，两个园区仍计入所有汇总数字——这是一个待回答的问题，而不是错误。

## 为什么有的园区等级偏低

多数低于 T2 的园区，要么缺少一项基本的定义性事实，要么有某个字段还没有任何人公开，要么依赖的来源是在检查规则收紧之前读取的。每晚更新会逐个处理它们，参见[数据如何保持更新](how-it-is-kept-current)。
