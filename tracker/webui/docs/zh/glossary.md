# 术语表

你在控制台和本文档中会遇到的术语，按英文字母顺序排列。

**Approximate (~)**（约数）——来源用“about”“roughly”或“an estimated”（约、大约、估计）等措辞加以保留的数字。参见[数字与日期](numbers-and-dates)。

**At least (+)**（至少）——来源作为下限给出的数字：“more than”“over”（超过、逾）。显示时末尾带有 **+**。

**Biggest obstacle**（最大障碍）——园区最严重的未解决障碍，用一句话描述。参见[阶段与进展](progress)。

**Blocking**（阻断）——最严重的障碍级别：工作已经停止。

**Buyer**（买方）——将使用园区容量的公司，可能与建设它的公司不同。[资本支出](capex)按买方汇总。

**Campus**（园区）——追踪系统中的一行记录：一家运营商在一个地点的场地。它可能包含多栋楼。

**Citation**（引用）——附在园区上的一个来源，连同它所支持的数值。

**Company**（公司）——每家公司一条记录：它唯一的名称、公司类型、母公司，以及合并到它名下的每一种写法。参见[公司页面](companies)。

**Confidence**（可信度）——0 到 3 的评分，表示一个园区的依据有多充分。参见[可信度](confidence)。

**Default**（默认值）——因为没有人说明、而该字段又不能为空而显示的数值；实际上就是*已宣布*这个阶段。参见[数值从哪里来](provenance)。

**Delay risk**（延期风险）——在[公司页面](companies)和[项目详情页](project-page)上，根据园区详情页上的证据判断它错过日期的可能性：日期已过却无投运消息、推迟两次或以上、或有已导致停工的障碍，为 *high*（高）；推迟过一次、有已影响进度的障碍、或一年内到期但尚无施工报道，为 *elevated*（较高）；其余为 *low*（低）。这是对证据的解读，不是预测。

**Derived**（推导）——查得或算出、而非报道的数值：人口普查地理信息、由兆瓦数换算的算力。

**Duplicate**（重复项目）——一个园区被存成了两行记录。参见[重复项目](duplicates)。

**Energized**（已通电）——电力已接通并开启。

**Facility power (◒)**（设施总功率）——整个场地的用电功率，包括冷却；通常比 IT 负载高 10–30%。

**Floor**（下限）——作为最小值的数字。[资本支出](capex)上的每一个总数都是下限。

**Forecast**（预期）——只是预计会发生、尚未发生的里程碑。绝不算作已达成。

**Former**（以往）——在某个园区的角色已经结束的相关方：租约终止的租户、已出售场址的业主。保留在园区页面上；现在不是任何人的买方。

**GW**（吉瓦）——gigawatt：1,000 兆瓦。

**H200-equivalent**（H200 等效）——把容量换算成 NVIDIA H200 加速器的数量，约每兆瓦 770 个。

**Held**（已保证）——系统在每次写入时强制执行的数字之间的关系；会打破它的写入将被拒绝。参见[数字之间的勾稽关系](invariants)。

**Hyperscaler**（超大规模云厂商）——为自用而建设或租用容量的大型云计算公司。

**Implied**（推定）——从更靠后的里程碑推断出、而非报道的里程碑（没有土地就不会动工）。电力从不推定。

**Inferred**（推断）——模型根据已存储的事实做出的判断，只用于可能的障碍和值得关注的信号。

**IT load**（IT 负载）——计算设备本身使用的功率。规划容量要衡量的就是它。

**Landlord**（数据中心房东）——建设数据中心并出租给他人的开发商。

**Material**（重大）——中间的障碍级别：有来源称进度或规模发生了变化。

**Merge**（合并）——把重复的行并为一行。无法撤销。

**MW**（兆瓦）——megawatt，电力容量的计量单位。所有容量列都以 MW 为单位。

**Nameplate (⚡)**（铭牌容量）——发电厂的额定输出；不是数据中心的负载。

**Neocloud**（新兴 GPU 云厂商）——出租 GPU 算力的公司；与超大规模云厂商一样，算作最终用户。

**n/a**（不适用）——因为该字段目前还不适用而为空，例如在任何部分建成之前的运行容量。

**No named customer**（无具名客户）——没有可识别买方的容量，在[资本支出](capex)中排在最后。

**Obstacle**（障碍）——据报道阻碍园区推进的因素：电网容量、许可、反对意见、水、供应、融资。

**Operator**（运营商）——建设并运营园区的公司。

**Overdue**（逾期）——在公司页面的供给图上，属于疑似延期园区的容量：仍在预期之中，但已没有任何人认可的日期。

**Party**（相关方）——参与某个园区的公司，连同它的角色：开发商、业主、运营商、客户、公用事业公司或承包商。

**Phase**（阶段）——园区的进展程度：已宣布、审批中、在建、运营中、暂停、已取消。

**Precision**（精度）——日期陈述的精确程度：日、月、季度、半年或年。

**PUE**（电能使用效率）——power usage effectiveness：设施总功率除以 IT 负载。现代大型场地约为 1.1–1.3。

**Quoted**（已引证）——有原句支撑的数值，追踪系统已核实该原句确实出现在文章中并陈述了这个数值。

**Relationship not yet closed**（尚未闭合的关系）——园区的来源尚未厘清的、其数字之间的关系，例如把园区描述了两次的分期。列在园区页面上；不改变任何数字。参见[数字之间的勾稽关系](invariants)。

**Ruled out**（已排除）——被判定为不同场地的一对记录；或被判定为并非描述本园区的一条说法。

**Scope**（范围）——一个数字涵盖的范围：本场地、单栋楼、整体计划、区域或资产组合。

**Serving**（服务中）——已有客户在其上运行的楼栋或分期。

**Shell complete**（主体完工）——已经建成但尚未通电的楼栋。

**Signal to watch for**（关注信号）——某条进展轨道上的下一个里程碑：能表明园区有所进展的消息。

**Statement**（陈述）——一个来源关于园区、分期、相关方、里程碑或障碍所说的一件事，连同其可信程度和背后的原句。每个数字都从中挑选。参见[数值从哪里来](provenance)。

**Superseded**（已被取代）——发布时正确、但之后已被重新表述的说法。

**Subsidiary**（子公司）——被记录为隶属于另一家公司（其母公司）的公司。它的园区和数字仍是它自己的。

**Supply**（供给）——在公司页面上，该公司被计入、尚未投运的容量，按每个园区的到期年份列出，涵盖今年及之后两年。

**Suspected delay**（疑似延期）——预计上线日期已过（以其所指的整个月份、季度或年份为准），之后却没有任何报道说它已投入运行的园区。参见[数字与日期](numbers-and-dates)。

**Tertiary source**（三手来源）——目录网站、维基或资讯汇编。只用于补缺。

**Tier (T0–T3)**（质量等级）——追踪系统衡量记录质量的阶梯：有来源、可靠、完整、已定。参见[质量等级](tiers)。

**Track**（进展轨道）——五条相互独立的进展阶梯之一：场地控制、审批、电力接入、施工、客户与资金。

**Tranche**（分期）——园区中的一栋楼、一期或一个机房，有自己的容量和状态。分期可以层层嵌套：楼栋属于某一期，某一期属于园区，园区中的每一兆瓦只计一次。属于另一个分期的别名、已被取代、或属于另一个园区的分期会被*搁置*（set aside），不计入任何数字。

**待确认**——“to be confirmed”（有待确认）：从文章中读取、但没有经过核查的原句支撑的数值。

**Watchlist**（关注列表）——你关注的公司和园区；决定你的 [Updates](updates)（动态）和晨报邮件的内容。
