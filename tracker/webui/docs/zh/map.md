# 地图

**Map**（地图）页面把每一个有位置信息的园区标在美国地图上，并在地图上方和下方给出全国及各州的合计数字。

> [!WARNING]
> 圆点位于园区登记所在**城镇或县的中心**，而不是场址本身。同一个城镇里的两个园区共用一个点，位于城外的园区也会显示在城里。这张地图用来看活动集中在哪里，而不是用来查找具体场址。

地图下方会说明有多少个园区有位置信息、被画在图上。没有位置信息的园区仍然可以在 [Projects](projects)（项目）页面找到，也仍计入各项合计数字。

## 合计数字

| 数字 | 统计什么 |
| --- | --- |
| **Campuses tracked**（跟踪的园区） | [Capex](capex)（资本支出）页面所统计的园区：不含已暂停和已取消的园区，疑似重复登记的园区只算一次。 |
| **Capacity planned**（规划容量） | 这些园区的规划容量，每个园区按整个园区的数字计。 |
| **Capacity operating**（运行容量） | 其中已经建成并投入运行的部分。 |
| **States**（州） | 这些园区分布在多少个州。 |

没有公布规模的园区按零计，因此两项容量都是下限。资本支出页面按买方列出的数字加起来可能略高，[公司页面](companies)也是如此，因为它们把这些买方数字分配到各家公司：一些园区的建筑按买方分别列出，其中少数园区的建筑容量之和超过了园区本身的数字，地图采用的是园区本身的数字。除此之外，三者统计的园区和计算方式都相同。

## 怎样读这张地图

- **颜色表示阶段**：已宣布、审批中、建设中、运行中、已暂停或已取消。已暂停和已取消的园区会画在图上，但不计入合计数字。
- **大小表示规划容量**，分五档：100 MW 以下、100–299 MW、300–999 MW、1–3 GW、3 GW 及以上。地图下方的图例列出了每一档。
- **空心虚线圈**表示没有人公布过该园区的规模 —— 不是规模小，而是未知。
- **州的颜色深浅**随该州的规划容量加深，从陆地的颜色渐变为琥珀色。
- 疑似重复登记的园区只画一个点。

## 控件

| 控件 | 作用 |
| --- | --- |
| **阶段按钮** | 每个按钮显示一个阶段的颜色和该阶段的圆点数量。点击可隐藏该阶段的圆点，再点一次即可恢复。 |
| **− / +** | 缩小或放大，范围是 1× 到 10×。两个按钮之间的数字是当前的缩放倍数。 |
| **Reset**（重置） | 回到全国视图。 |

也可以用滚轮或双指捏合缩放，拖动可移动地图。缩放时圆点大小保持不变，所以像北弗吉尼亚这样密集的地区放大后就能分开看清。

**把鼠标悬停在圆点上**，可以看到园区名称、所属公司（用每个页面都相同的唯一名称）和地点、所处阶段和规划容量，以及是否有障碍在阻碍它。**点击圆点**即可打开[它的页面](project-page)。**悬停在一个州上**，可以看到该州有多少个园区以及规划容量。

## 按州统计

地图旁边（窄屏时在地图下方）的表格列出每一个有计入园区的州，按规划容量从大到小排列，并显示各州的园区数量。表格可以单独滚动，统计方式与上方的合计数字相同。
