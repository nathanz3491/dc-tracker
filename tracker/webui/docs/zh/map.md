# 地图

**Map**（地图）页面把每一个有位置信息的园区标在美国地图上。

> [!WARNING]
> 圆点位于园区登记所在**城镇或县的中心**，而不是场址本身。同一个城镇里的两个园区共用一个点，位于城外的园区也会显示在城里。这张地图用来看活动集中在哪里，而不是用来查找具体场址。

页面会说明有多少个园区有坐标；其余园区仍会出现在地图旁边的列表中。

## 控件

| 控件 | 作用 |
| --- | --- |
| **Flat / Relief**（平面 / 立体） | 平面地图，或带柱体的 3D 视图。只有在浏览器支持时才提供 Relief。 |
| **colour**（颜色） | 按 **phase**（阶段）、**confidence**（可信度）或 **operator**（运营商）给圆点着色。 |
| **state fill**（州填充） | 按 **project count**（项目数）、**cited MW**（有引用的兆瓦数）给各州着色，或不着色（仅限平面地图）。 |
| **Operator clusters**（运营商聚类） | 在每个运营商的站点周围画一个虚线圈，标注运营商名称和站点数量（仅限平面地图）。 |
| **− / zoom / +**（− / 缩放 / +） | 在 1× 到 12× 之间缩放（仅限平面地图）。 |
| **Reset view**（重置视图） | 回到全国视图。 |

## 平面地图

- 圆点的**面积随规划容量增大**。**空心虚线圈**表示该园区没有任何有引用的容量 —— 不是规模小，而是未知。
- **闪烁的红色光晕**标记有严重到足以使工作停止的未解决障碍的园区。
- 可以用滚轮、双指捏合或按钮缩放，拖动可移动地图。缩放时圆点大小保持不变。
- 把鼠标悬停在一个州上，可看到它有多少个园区和多少有引用的兆瓦数。悬停在圆点上可看到园区、地点和容量；点击即可打开[它的页面](project-page)。
- 图例解释阶段或可信度的颜色。按 **operator** 着色时没有图例，而且只有五种颜色循环使用，所以两个运营商可能共用一种颜色。

## 立体视图

柱体高度随规划容量升高；一个短而淡的标针表示没有有引用容量的园区。各州按其拥有的园区数量着色。视图会缓慢旋转几秒钟；拖动可旋转，滚动可缩放。在 Relief 中，**operator** 着色会退回为按阶段着色。

## 列表

地图旁边列出每一个园区，按规划容量排序 —— 包括没有坐标的园区 —— 并显示其地点、阶段，以及是否有什么在阻碍它。点击即可打开。
