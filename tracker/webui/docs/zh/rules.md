# 规则

**规则**是我们跟踪的、会同时影响多个项目的政策或法律：某个州暂停审批新的数据中心、某个镇禁止大型数据中心、电网运营机构针对大负荷新用户的规定、全州范围的税收优惠等。每条规则都会列出它影响的项目。

## 每条规则显示什么

| | |
| --- | --- |
| **Status**（状态） | *proposed*（已提出）、*pledged*（在任或当选官员已承诺）、*passed*（已通过）、*in force*（已生效）、*blocked*（被法院叫停）、*lifted*（已废止）或 *voted down*（被否决）。 |
| **Effect**（作用） | *restricts*（限制）—— 让建设更难，如禁令、暂停令、新增成本；*eases*（放宽）—— 让建设更容易，如免税、快速审批。 |
| **Need**（涉及需求） | 影响哪方面，用词和障碍相同：审批、电网容量、用水…… |
| **Projects affected**（受影响项目） | 该地区内处于规则覆盖阶段的项目（例如只限尚未拿到许可的），如果规则设了规模门槛，则只限门槛以上的项目。 |
| **Articles**（文章） | 规则所依据的新闻，附上写明规则的原句。 |

## 确定与可能

- **exact**（确定）：项目所在的州或县正是规则针对的州或县。
- **likely**（可能）：按项目登记所在的城镇或电网辖区匹配，或项目规模未知。使用前请核实 —— 我们没有每个园区的确切场址。

## 需要知道的

- 规则不算项目的障碍：不计入障碍数，不改变项目的任何数值，也不会让项目在 [Monitor](monitor)（关注）页面上显示为受阻。
- 州议会里尚未通过的议案只做列示，通过之前不影响任何项目。
- 针对全国或全行业的规则（如关税、芯片出口管制）列在 **Market**（市场）一栏，不影响任何项目。

## 规则出现在哪里

- **Rules**（规则）页面 —— 按州查看所有规则；勾选 *Include lifted and voted down* 可加上已失效的规则。
- [项目详情页](project-page) —— **Exposed to**（受其限制）列出限制该项目的规则，**Helped by**（受其利好）列出放宽的规则。
- [Monitor](monitor)（关注）页面 —— **Rules for their places**（所在地的规则）列出影响你所关注项目的规则。
- 每日邮件 —— 影响你项目的规则状态有变化时，会附上一张卡片。
