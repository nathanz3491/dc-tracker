# 阶段与进展

追踪系统用两种方式描述一个园区进展到哪一步：一个单一的**阶段**，以及五条相互独立的**进展轨道**。阶段是简短的回答；进展轨道才是如实的回答。

## 阶段

| 阶段 | 含义 |
| --- | --- |
| **announced**（已宣布） | 已公开；尚未提交任何正式申请。 |
| **permitting**（审批中） | 正在申请规划分区、许可或审批。 |
| **construction**（在建） | 正在建设。 |
| **operational**（运营中） | 至少有一部分已经运行。 |
| **paused**（暂停） | 工作已停止，依据是开发商自己的说法或某个来源的说法。 |
| **cancelled**（已取消） | 已放弃。 |

前四个阶段是一个阶梯。*Paused* 和 *cancelled* 不在这个阶梯上：当可信来源说某个园区已经停止时，这一点优先于它此前已推进到的程度。

当来源在阶段上意见不一时，以已引证来源支持的、推进最远的阶段为准，除非有来源说该园区已经停止。具名楼栋也能推动园区的阶段向前：如果有来源说某栋具名楼栋已经运行，则该园区至少处于运营中。只有当园区的*每一栋*楼都已停止时，园区才会因其楼栋而被判定为已取消。

如果没有任何来源说明阶段，这一行会显示 **announced**，但这是[默认值（default）](provenance)，而不是报道出来的事实。

[Capex](capex)（资本支出）页面的汇总不包括暂停和已取消的园区。

## 五条进展轨道

单一的阶段会掩盖大部分重要信息。一个园区可能已经拥有土地、拿到了许可，却仍要为电网接入等上好几年。因此，进展还会在五条各自独立推进的阶梯上跟踪：

| 进展轨道 | 里程碑（按顺序） |
| --- | --- |
| **site control**（场地控制） | 已宣布 → 已取得土地 |
| **permits**（审批） | 已提交许可申请 → 许可已获批 |
| **power**（电力接入） | 并网协议 → 已通电 |
| **construction**（施工） | 场地施工 → 破土动工 → 设备已安装 |
| **customer & finance**（客户与资金） | 首个客户 |

每条轨道的状态是它已达到的最新里程碑。尚未达到的下一个里程碑就是**signal to watch for**（需要留意的信号）：也就是能表明园区正在推进的新闻。

### 推定的里程碑

有些里程碑意味着更早的里程碑已经完成：没有土地就不可能破土动工。当报道了某个较后的里程碑时，它所隐含的较早里程碑会显示为**推定**：在 [Projects](projects)（项目）页面中颜色较淡，在项目时间线上显示为空心，因为推论不是来源。

**电力接入永远不会由施工推定。** 在并网之前先行建设是常态，而一栋已经建好、正在等待变电站的楼，正是追踪系统能向你展示的最有用的信息之一。只有当来源明确说明时，电力接入才算达成。

### 障碍与进展轨道

每个未解决的障碍会卡住一条进展轨道：

| 障碍 | 卡住的进展轨道 |
| --- | --- |
| 电网容量、输电 | 电力接入 |
| 审批、社区反对、环境、用水 | 审批 |
| 设备供应、芯片供应 | 施工 |
| 融资、没有已承诺的客户 | 客户与资金 |

存在未解决障碍的进展轨道会以红色显示为 **blocked**（受阻）。

## 尚未发生的里程碑

只有当里程碑的日期已经过去，并且来源报道它已完成时，才算达到。诸如"预计于 2027 年开始运营"之类的措辞属于**预期（尚未发生）**：它会被保留，标注为 *expected, not reached*（预期，尚未达到），但永远不计入。在 [Updates](updates)（动态）页面上，这类新闻会标注 **expected, not reached**。

## 障碍

| 字段 | 取值 |
| --- | --- |
| **Kind**（类型） | 电网容量、输电、审批、环境、设备供应、芯片供应、融资、没有已承诺的客户（承购）、社区反对、用水 |
| **Severity**（严重程度） | *watch*（关注）：已提出，未说明影响；*material*（重大）：有来源说进度或范围已改变；*blocking*（阻断）：工作已停止 |
| **Status**（状态） | 未解决、已解决、已被取代 |

多数障碍属于*关注*级别：来源很少直接说某件事改变了进度。一行数据上的**最大障碍**是最严重的那个未解决障碍，优先选有原句支持的；当两个障碍同样严重时，选哪一个是随意的，项目详情页会注明这一点。
