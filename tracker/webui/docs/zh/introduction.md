# dc-tracker 是什么

dc-tracker 跟踪美国各地正在建设的数据中心园区：规划了多少容量、已有多少在运行、背后有多少资金、为谁而建，以及什么可能拖慢进度。每个数字都标明出处；有原句的，精确到那一句。

## 你可以用它做什么

- **跟踪你关心的动态。** 把公司、租户或单个园区加入关注列表，[Updates](updates)（动态）页面和晨报邮件就会告诉你媒体对它们报道了什么。参见 [Monitor](monitor)（关注）。
- **查找一个园区。** [Projects](projects)（项目）表格收录了系统所知的每一个园区，每个园区都有[自己的页面](project-page)，列出它的数字、数字背后的来源、分期、障碍和时间线。
- **看清谁在出钱。** [Capex](capex)（资本支出）按买方汇总容量和投资：买方是真正使用这些楼栋的公司，而不只是建造它们的公司。
- **亲自核对一个数字。** 把鼠标悬停在任何数值上，即可看到它所依据的原句；打开 [Sources](sources)（来源），可以看到整个数据集依赖哪些发布方。

## 背后的一条原则

模型从文章里读出的内容，并不自动算作事实。文章由语言模型阅读，它提取的每个数值都必须附上一句原文中真实存在、并且确实陈述了这个数值的句子。通过检查的数值显示为已引证（quoted）；未通过的数值会保留，但标为 **待确认**（即"有待确认"），并且不计入系统担保的任何内容。[数值从哪里来](provenance)解释了你会看到的各种标签。

> [!TIP]
> 如果这套文档你只读一页，请读[数值从哪里来](provenance)。控制台里的每个数字都带有其中一种标签，而标签决定了你应该在多大程度上信任它。

## 覆盖什么，不覆盖什么

| 覆盖 | 不覆盖 |
| --- | --- |
| 美国的数据中心园区，从首次宣布到投入运营 | 美国以外的站点 |
| 以兆瓦（MW）计的规划容量和运行容量、投资、日期、租户、阶段 | 租金、价格、合同条款 |
| 新闻报道的障碍：电力、审批、反对、用水、供应链、资金 | 非公开信息；所有内容都来自公开来源 |
| 里程碑：土地、审批、电力接入、施工、首个客户 | 系统自己的预测；系统只报告来源说了什么 |

数据收集自公开来源：新闻和行业媒体、运营商自己的公告、政府文件和公司申报文件。[数据来源](methodology)介绍了这些来源，[数据如何保持更新](how-it-is-kept-current)介绍了每日更新。
