# 你的账户

点击控制台右上角你的名字，可打开 **your account**（你的账户）。

## 修改密码

输入两次新密码，然后点击 **Change password**（修改密码）。系统不会要求你输入旧密码，因为你已经登录。修改密码会**让你在其他所有设备上退出登录**；你正在使用的设备保持登录。

如果忘记了密码，请退出登录，然后在登录页使用 **Forgot password?**（忘记密码？）。参见[账户与登录](signing-in)。

## API 密钥

**API keys**（API 密钥）让程序以你的访问权限，通过 API 读取追踪系统的数据。给密钥起个名字，点击 **Create key**（创建密钥），然后立即复制：密钥以 `dct_` 开头，只显示这一次。列表显示每个密钥的名称、开头几个字符、创建时间和最近使用时间，以及一个 **Revoke**（撤销）按钮；撤销后密钥立即失效。一个账户最多可以有五个有效密钥。参见 [API 入门](api)。

## 系统保存了你的哪些信息

- 你的电子邮件地址，以及你填写过的姓名；
- 你的密码，只以无法还原为原密码的形式保存；
- 你的[关注列表](monitor)，以及哪些动态已经通过邮件发送给你；
- 你最近一次登录的时间；
- 是否为你开启了 AI 面板；
- 你的 API 密钥的名称、开头几个字符和相关日期，但绝不保存密钥本身。

## 管理员须知

具有管理员权限的账户会在名字旁边看到一个 **Admin**（管理）按钮。Admin 页面分为两部分。

### 等待批准

已确认电子邮件的注册申请，显示邮件地址、姓名，以及注册和确认的时间。

- **Approve**（批准）让此人进入，并发邮件通知其账户已就绪。
- **Approve with AI panels**（批准并开启 AI 面板）效果相同，同时为其开启 AI 面板。
- **Turn down**（拒绝）会在请你确认后删除该申请。

### 账户

列出每个账户，包括角色、状态（*active*（已启用）、*disabled*（已停用）、*waiting for approval*（等待批准）、*email not confirmed*（邮件未确认））、可见范围（*everything*（全部），或其关注的条目数）以及最近登录时间。点击某一行即可编辑：

- **sign-in email**（登录邮箱）和 **display name**（显示名称）；
- **Sees the whole database**（查看整个数据库）：即此人的 *watch everything*（关注全部）设置。每个账户本来就能读取全部数据；这个开关只是把他们的 Updates（动态）和 Monitor（关注）页面扩展到全部内容，并停止向其发送晨报邮件；
- **May use the AI panels (they spend tokens)**（可使用 AI 面板（会消耗 token））；
- **Set a new password**（设置新密码）：直接设置，不会给此人发送邮件；
- **Sign out everywhere**（全部退出登录）：结束其所有会话；
- **Disable / Enable**（停用 / 启用），以及 **Delete**（删除），后者会永久删除该账户及其关注列表。

停用账户也会让其 API 密钥失效；删除账户则会同时删除这些密钥。你不能停用或删除自己的账户。将某人设为管理员、创建邀请码，都由追踪系统的维护者完成，不在本页操作；尚未使用的邀请码列在页面底部，并注明到期日期。
