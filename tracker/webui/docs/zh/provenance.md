# 数值从哪里来

控制台中的每个数值都带有一个标签，说明由谁为它担保。标签直接体现在数值的样式上（颜色和下划线），一眼就能分辨；鼠标悬停在数值上，会显示它背后的原句或来源。

## 标签

| 样式 | 标签 | 含义 |
| --- | --- | --- |
| {{v:reported|1,200 MW}} | **已引证（quoted）** | 有来源说过这个值，而且追踪系统核实过：这句原句确实出现在文章里，也确实说的是这个值。这是数值能达到的最高可信状态。 |
| {{v:derived|Loudoun County}} | **推导（derived）** | 查得或算得，而不是报道出来的：根据美国人口普查数据得到的县名或坐标、由兆瓦数换算的算力、从园区楼栋推得的园区租户。可以核查，但没有人针对这个园区这样说过。 |
| {{v:unconfirmed|1,200 MW}} | **待确认** | 意思是"有待确认"。从文章中读出，但找不到能支持它的原句。保留下来以便核查；在核实之前，它在[可信度](confidence)中不计任何分。 |
| {{v:inferred|电网容量}} | **推断（inferred）** | 模型根据已存储事实作出的判断。只用于可能的障碍和需要留意的事项，从不用于数字、日期或公司。 |
| {{v:defaulted|announced}} | **默认值（default）** | 没有任何来源提及，而该字段又不能为空，所以显示后备值。实际上就是：没有来源说明过的 *announced*（已宣布）阶段。 |
| {{v:missing|—}} | **空（null）** | 为空。这往往就是正确答案，参见[为什么字段为空](empty-fields)。 |
| {{v:na|—}} | **不适用（n/a）** | 为空，而且不可能是别的值：例如尚未建成任何设施的园区的运行容量。 |

这些样式不仅颜色不同，线型也不同（无下划线、点线、虚线），所以不靠颜色也能区分。

## 原句核查

数值是由语言模型从文章中读出来的。模型可能读错、张冠李戴，甚至凭空编造，所以追踪系统不会轻信它：

1. 每个数值都必须附带陈述它的**原句**。
2. 这句原句必须**确实出现在**已发表的文章中。如果模型改写了措辞，追踪系统会找到文章自己的原句，找不到就拒绝；系统保存的是文章的原文，从不保存模型的措辞。
3. 这句原句必须**确实陈述了这个值**。数字会先换算单位再比较，因此"1.2GW"可以支持 1,200 MW；但如果原句真实存在、说的却是别的内容，则不算数。

三项都通过的数值标为**已引证**。任何一项不通过的，保留为**待确认**。

## 两种待确认

一个待确认的值之所以未确认，有两种截然不同的原因，应对方式正好相反：

- **没有依据支持它。** 模型没有给出原句，或者原句不在文章中，或者原句没有陈述这个值。这个数字可能是对的，只是追踪系统无法证明。请寻找其他来源。
- **它属于别的东西。** 原句是真实的，但这个数字太大，不可能只属于这个园区。通常是一篇讲单个园区的文章引用了公司的整体计划，比如"a $500 billion buildout"（5000 亿美元的扩建计划）。这类数值会用红色标注 **not this site's figure**（不是本园区的数字）。数字本身是真的，只是对应错了对象。

## 弹出卡片显示什么

鼠标悬停在数值上会弹出一张小卡片，内容包括：

- 标签；
- 适用时，以红色显示 **not this site's figure**；
- 当这个数字涵盖的不是整个园区时，说明它涵盖什么：*programme*（整体计划）、*region*（区域）、整个 *portfolio*（资产组合）、单个 *building*（楼栋），或某个具名的期；
- 当来源提到它时并非单纯的规划，说明来源的说法是 *speculated*（推测）、*targeted*（目标）、*contracted*（已签约）还是 *achieved*（已实现）；
- 加引号的原句；如果该字段没有记录原句，则显示来源摘录，并注明 *from the source excerpt, not this field's own sentence*（取自来源摘录，并非该字段自己的原句）。

## 来源意见不一时

每个园区都根据其所有来源的内容整体重建，从不一点一点地手工编辑。当来源在某个字段上意见不一时，追踪系统按以下顺序选择：

1. 已被排除的说法（被发现说的是别的东西，或被后来的说法取代）不再计入。
2. 已引证的说法优先于待确认的说法。
3. 针对整个园区的数字优先于针对单个楼栋的数字。
4. 第一手来源优先于目录网站或维基，后者只用于填补空缺。
5. 然后按该字段自己的规则：多数字段取最新且最可靠的来源，运行容量取最大值（它只会增长），宣布日期取最早的。

项目详情页上的 **N other claims**（另有 N 条说法）会显示所有相互竞争的值，以及保留了哪一个。[字段说明](fields)列出了每个字段的规则。
